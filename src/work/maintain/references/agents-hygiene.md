# AGENTS.md hygiene job

**Load when:** `/work:maintain` runs the **agents** job — bare ritual (always check
alongside prune), `--all`, `--agents`, or combined with `--prune`.

## Intent

`AGENTS.md` (L2 always-load project guide) drifts into a **bucket of corrective actions** —
always-on Type A tax. This job **checks** and, only with approval, proposes moves so AGENTS
stays **orienting pointers only**.

**Not a wipe.** Prefer extract + pointer over silent delete. Everything recoverable via git.

## Quality bar (orienting only)

| Keep in AGENTS | Move out |
|----------------|----------|
| Project identity / what this repo is | Step-by-step recovery rituals |
| Planning root / conventions pointer | Long process essays (→ skills) |
| Memory-link / charter-link marker blocks | Incident corrections (→ dated rules / `.agent-tools/memory/`) |
| Few truly always-on hard prefs | Model/tool workarounds and “don’t do X again” walls |
| Links to setup, key surfaces | Dual residence of skill procedure |

Marker-bounded blocks from setup (`agent-tools:memory-link`, `agent-tools:charter-link`) are
**keep** — refresh text only if setup/re-setup owns the block format.

## Scope

| Path | Action |
|------|--------|
| Repo-root `AGENTS.md` | Primary target |
| `CLAUDE.md` if present and **not** a symlink to AGENTS | Report dual-content risk; propose merge into AGENTS + symlink |
| User-global L1 (`~/.claude/CLAUDE.md`, etc.) | **Out of scope** for this job (memory job / personify may touch L1) |

## Procedure

1. **Locate** `AGENTS.md` at repo root (and CLAUDE.md as above). If missing → report
   “no AGENTS.md — optional `/work:setup` / `/work:setup`” and stop job (not an error).  
2. **Inventory** sections / major blocks; rough line count.  
3. **Classify** each block: `orienting` · `pointer` · `corrective` · `process_duplicate` ·
   `stale` · `marker_block`.  
4. **Present summary** (table): section · class · proposed disposition
   (`keep` / `→ memory entry` / `→ conventions` / `→ skill pointer` / `delete`).  
5. **Apply only after explicit second confirmation** listing each change. Default if unclear:
   keep.  
6. Prefer **move content** to `.agent-tools/memory/entries/` (with user approval via memory
   promote shape) or shorten to a one-line pointer — do not leave knowledge only in chat.  
7. Write cadence: `last_agents_at`, `last_agents_result`
   `{ lines, orienting, corrective, proposed, applied, cancelled }`.

## Hard refuses

- No delete/rewrite of AGENTS without explicit apply confirmation  
- No clobber of marker-bounded setup blocks except refresh of known marker content  
- No skill corpus edits (process IP → evolve / compound evidence only)  
- Do not invent NEXT or claim units

summary stays short; this file is the full list.

1. Invent a next unit or NEXT pointer (unlisted / fatigue / residual-only).
2. Hard-stop solely because a named unit lacks a planning directory.
3. Auto-author roadmaps or brainstorm seeds (stop + offer unless unit SM routes there).
4. Author plan/requirements content — phase skills do.

7. Skip compound after integrate without explicit `compound: none`.
8. Push/PR unless project push policy allows — never production promotion.

   grab items an active parallel-mode worker owns when in unit mode.

12. Emit end-of-loop recap on user-approval stops.

    `/skills:evolve` when available (else upstream escalate; see `soft-checks.md`).

    `DESIGN_FALSIFIED`, `HUMAN_STEER`, structural review findings).

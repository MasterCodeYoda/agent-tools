# Phase skill control-plane budget

## Why

Always-on phase skills (execute, plan, continue) tax every invocation. After the frontier
decontaminate pass, execute/plan still re-embedded recovery essays, slice commit cookbooks,
and context-gathering steps that already belong in progressive-disclosure refs.

Further polish cut execute ~306→~141 and plan ~334→~121 without demoting hard refuses or
mandatory loads.

## How to apply

1. **SKILL.md keeps:** flags/errors, input table, init order, loop triggers, hard refuses,
   DoD bullets, integration pointers, “load X end-to-end”.  
2. **Extract when prose is:** multi-step recovery, slice commit recipes, research/design
   gather sequences, approval save cookbooks.  
3. **Design targets:** phase orchestrators ~≤150–200 lines after siblings exist; parent
   status surfaces even thinner.  
4. **Verify:** `doc_lint` + conservation (gates still in skill or mandatory-load ref).
